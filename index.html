Projects

isiXhosa Tech Glossary

Python · FastAPI · PostgreSQL

A searchable list of computing terms in English and isiXhosa, with a website and a REST API. You can search in either language, and the closest matches come first. Anyone can suggest a new term or a better translation, and it only goes live after it's been reviewed.

It runs on Render with a Neon PostgreSQL database. The tests run against both SQLite and PostgreSQL on every push, and the site only deploys if they pass.

Stokvel Manager

Java · Spring Boot · PostgreSQL

An API for running a stokvel, a rotating savings group. It tracks each member's contributions, whose turn it is to be paid, and who is in arrears, and it produces a statement per member. A payout is blocked until everyone has paid for that round.

Database changes are versioned with Flyway, money is stored as exact decimals, and errors come back in a standard format. Integration tests run against H2 and PostgreSQL in CI.

Code

Offline School Register

C# · ASP.NET Core · EF Core · JavaScript

An attendance register for schools with unreliable signal. Teachers mark learners on their phone with or without a connection, and the changes sync when signal comes back. Several teachers can mark the same class and their phones end up agreeing.

The app and its data stay on the phone (service worker and IndexedDB). The sync API is safe to retry, the newest tap wins when two phones disagree, and each phone only downloads what changed since its last sync.

Master's research: climate-smart learning

Python · Flask · scikit-learn

A web app that recommends climate change learning modules to high school learners in the rural Eastern Cape. A Random Forest model uses each learner's school profile and what their families deal with at home, such as drought, floods and farming. Every topic page is in English and isiXhosa.

The code is private while the dissertation is being reviewed.
